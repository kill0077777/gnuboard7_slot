# 그누보드7 슬롯머신 보안 패치 및 확장 소스

제로보드 기반 슬롯머신 소스를 그누보드7 이식에 사용할 수 있도록 정리한 작업본입니다.

## 포함 기능

- 슬롯머신 원본 이미지 및 SWF 파일 보존
- 슬롯 게임 보안 패치
- CSRF·로그인·관리자 권한 검증
- 포인트 차감 시 잔액 조건 및 동시 요청 방어
- 전체랭킹게시판
- 이벤트게시판
- 게임포인트와 통합 포인트를 위한 충전·선물 기능
- 회원 하루 1회 50,000포인트 무료 충전
- 포인트 충전·선물 원장 기록

## 주요 경로

- `smain.php`, `sub.php`: 슬롯머신 화면과 게임 처리
- `ranking.php`: 전체랭킹게시판
- `event.php`: 이벤트 목록 및 상세 화면
- `point.php`: 통합 포인트 확인·충전·관리자 선물 화면
- `security.php`: 인증·CSRF·입력 검증 보조 코드
- `*.sql`: 테이블과 인덱스 생성 SQL
- `images/`: 원본 이미지 파일
- `swf/`: 기존 플래시 리소스

## 설치 순서

1. 기존 그누보드7 회원·포인트 구조를 확인합니다.
2. `event.sql`, `point.sql`, `ranking.sql`을 필요한 순서로 검토한 뒤 DB에 적용합니다.
3. 소스 파일을 슬롯 모듈 경로에 배치합니다.
4. `db.php`의 PDO 연결 설정을 그누보드7 DB 설정 또는 `SLOT_DB_*` 환경변수에 맞춥니다.
5. 게임 차감·결과 계산·포인트 지급 전체를 하나의 DB 트랜잭션으로 연결합니다.
6. 설치가 완료되면 `install.php`는 웹에서 제거하거나 접근을 차단합니다.

## 중요 사항

현재 소스는 첨부된 구형 회원 테이블·컬럼을 기준으로 한 이식용 작업본입니다. DB 접근은 `db.php`의 PDO 준비문과 트랜잭션으로 통일했지만, 실제 그누보드7 운영 환경에서는 회원 테이블·회원 ID·포인트 컬럼 매핑을 확인해야 합니다.

기존 `images/` 파일은 변환하지 않았습니다. 구형 Flash SWF는 최신 브라우저에서 실행되지 않을 수 있으므로 운영 환경에서는 HTML5 효과로 대체하는 것을 권장합니다.

## 최근 PHP 보안 수정

GET 기반 게임 실행을 POST로 전환하고 CSRF·입력 검증·SQL 오류 노출·외부 이벤트 이미지 경로·구형 중복 진입 파일을 추가 점검했습니다. 상세 내용은 [PHP 보안 수정 내역](SECURITY_FIXES_KO.md)을 확인하세요.


## DB 계층

모든 PHP 쿼리는 `db.php`의 PDO 계층을 사용합니다. 그누보드 설정 상수(`G5_MYSQL_HOST`, `G5_MYSQL_USER`, `G5_MYSQL_PASSWORD`, `G5_MYSQL_DB`)를 사용할 수 있으며, 독립 실행 시에는 `SLOT_DB_DSN`, `SLOT_DB_USER`, `SLOT_DB_PASSWORD` 또는 `SLOT_DB_HOST`, `SLOT_DB_PORT`, `SLOT_DB_NAME` 환경변수를 설정합니다.
